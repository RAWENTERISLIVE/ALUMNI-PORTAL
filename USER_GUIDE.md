# 📖 Alumni Portal User Guide

## 🚀 Getting Started

### Accessing the Application
1. Open your browser and go to: **http://localhost:8080**
2. You'll see the homepage with login/register options

### For First-Time Users

#### Registration
1. Click "Register" on the homepage
2. Fill in your details:
   - Full Name
   - Email Address
   - Admission Number (format: 12345/23)
   - Admission Year
   - Password (minimum 8 characters)
3. Click "Register"
4. Check your email for verification (if email service is configured)

#### Login
1. Click "Login" on the homepage
2. Enter your email and password
3. Click "Sign In"

## 🧭 Navigation Guide

### Main Pages

#### 1. Dashboard
- **What it shows**: Activity feed, quick stats, recent activities
- **Key features**: 
  - View recent posts from alumni
  - See platform statistics
  - Quick action buttons
  - Featured groups preview

#### 2. Directory
- **What it shows**: Alumni profiles with search and filtering
- **Key features**:
  - Search by name, graduation year, location
  - Filter by department, year, location
  - View contact information
  - Connect with alumni

#### 3. Jobs
- **What it shows**: Job postings and opportunities
- **Key features**:
  - Browse available jobs
  - Post new job opportunities
  - Apply for positions
  - Filter by location, type, company

#### 4. Groups
- **What it shows**: Alumni groups and communities
- **Key features**:
  - Join existing groups
  - Create new groups
  - Participate in group discussions
  - View group members

#### 5. Mentorship
- **What it shows**: Mentor/mentee matching platform
- **Key features**:
  - Register as mentor or mentee
  - Browse available mentors
  - Book mentorship sessions
  - Manage your mentorship profile

#### 6. Posts
- **What it shows**: Social feed and announcements
- **Key features**:
  - Create new posts
  - Like and comment on posts
  - Share updates and news
  - Filter by categories

#### 7. Settings
- **What it shows**: Profile and account management
- **Key features**:
  - Edit profile information
  - Manage privacy settings
  - Configure notifications
  - Change password

### Admin-Only Pages

#### 8. Admin Panel (Super Admin Only)
- **What it shows**: Platform management tools
- **Key features**:
  - Manage user accounts
  - View platform analytics
  - Moderate content
  - Configure system settings

## 🔧 Common Tasks

### Creating a Post
1. Go to Posts page
2. Click "Create Post"
3. Add title and content
4. Select category
5. Click "Publish"

### Applying for a Job
1. Go to Jobs page
2. Find a job you're interested in
3. Click "Apply"
4. Fill in application details
5. Submit application

### Joining a Group
1. Go to Groups page
2. Browse available groups
3. Click "Join" on groups you're interested in
4. Participate in group activities

### Updating Your Profile
1. Go to Settings page
2. Edit your information
3. Update privacy preferences
4. Save changes

### Finding Alumni
1. Go to Directory page
2. Use search bar or filters
3. Browse through results
4. Click on profiles to view details

## 🛠️ Admin Functions

### Managing Users (Admin Only)
1. Go to Admin Panel
2. View user list
3. Approve/reject pending users
4. Suspend or activate accounts

### Viewing Analytics (Admin Only)
1. Go to Admin Panel
2. Check user statistics
3. Monitor platform activity
4. Export reports if needed

## 🆘 Troubleshooting

### Can't Login?
- Check your email and password
- Ensure your account is verified
- Contact admin if account is suspended

### Page Not Loading?
- Refresh the browser
- Check internet connection
- Clear browser cache

### Can't See Certain Features?
- Check your user role (some features are admin-only)
- Ensure your profile is complete
- Verify account status

## 📞 Getting Help

If you encounter any issues:
1. Check this user guide first
2. Try refreshing the page
3. Contact system administrator
4. Report bugs to technical team
